## Gabarito Detalhado

### Exercicio 1
**Pergunta:** O que o Flexbox organiza por vez?

- A) Altura e largura ao mesmo tempo.
- B) Duas dimensoes.
- C) Scripts internos.
- D) Banco de dados.
- **E) CORRETA — Uma dimensao.**

> **Resposta: E** — O Flexbox (Flexible Box Layout) organiza elementos em UMA dimensao por vez: linha (row) ou coluna (column). Para duas dimensoes, usa-se o Grid.

---

### Exercicio 2
**Pergunta:** Como ativar o Flexbox?

- A) flex-wrap
- **B) CORRETA — display: flex**
- C) justify-content
- D) grid-template-columns
- E) order

> **Resposta: B** — Para ativar o Flexbox em um container, usa-se a propriedade CSS `display: flex` no elemento pai.

---

### Exercicio 3
**Pergunta:** Qual propriedade organiza itens em linha ou coluna?

- A) justify-content
- B) grid-flow
- **C) CORRETA — flex-direction**
- D) gap
- E) span

> **Resposta: C** — A propriedade `flex-direction` define se os itens flex serao dispostos em linha (row) ou coluna (column).

---

### Exercicio 4
**Pergunta:** Quando usar Grid?

- **A) CORRETA — Para layouts bidimensionais.**
- B) Para grids unidimensionais.
- C) Para listas simples.
- D) Para animacoes.
- E) Para menus simples.

> **Resposta: A** — O CSS Grid e ideal para layouts bidimensionais (linhas E colunas ao mesmo tempo), sendo mais poderoso que o Flexbox para estruturas de pagina completas.

---

### Exercicio 5
**Pergunta:** Qual propriedade cria colunas no Grid?

- A) grid-size
- B) flex-direction
- C) inline-grid
- D) column-flow
- **E) CORRETA — grid-template-columns**

> **Resposta: E** — A propriedade `grid-template-columns` define o numero e o tamanho das colunas em um container Grid.

---

### Exercicio 6
**Pergunta:** Qual unidade e usada no Grid para dividir espaco proporcional?

- A) px
- B) rem
- **C) CORRETA — fr**
- D) %
- E) vw

> **Resposta: C** — A unidade `fr` (fraction) e exclusiva do CSS Grid e representa uma fracao do espaco disponivel, permitindo distribuicao proporcional de colunas e linhas.

---

### Exercicio 7
**Pergunta:** Layout fluido utiliza como base o que?

- **A) CORRETA — Unidades flexiveis.**
- B) Apenas pixels.
- C) Medidas fixas.
- D) Tabelas antigas.
- E) Graficos externos.

> **Resposta: A** — Layouts fluidos utilizam unidades flexiveis como %, vw, vh, fr e em, permitindo que o layout se adapte proporcionalmente ao tamanho da tela.

---

### Exercicio 8
**Pergunta:** Qual desafio dos layouts fluidos?

- A) Perda de responsividade.
- B) Funcionam so no Chrome.
- C) Nao aceitam fonts.
- D) Nao funcionam com CSS.
- **E) CORRETA — Elementos podem ficar largos demais.**

> **Resposta: E** — O principal desafio dos layouts fluidos e que, sem limites definidos (max-width), os elementos podem ficar excessivamente largos em telas muito grandes.

---

### Exercicio 9
**Pergunta:** Qual recurso moderno muda estilo conforme o tamanho do container?

- A) Media Queries.
- **B) CORRETA — Container Queries.**
- C) Flex-wrap.
- D) Subgrid.
- E) Gap.

> **Resposta: B** — Container Queries (introducao moderna do CSS) permitem aplicar estilos baseados no tamanho do container pai, e nao da viewport como as Media Queries tradicionais.

---

### Exercicio 10
**Pergunta:** Quando usar Flexbox?

- A) Dashboards complexos.
- B) Grids extensos.
- **C) CORRETA — Elementos em sequencia.**
- D) Cabecalhos fixos.
- E) Scripts assincronos.

> **Resposta: C** — O Flexbox e ideal para organizar elementos em sequencia (uma linha ou coluna), como menus de navegacao, listas de cards ou grupos de botoes.
