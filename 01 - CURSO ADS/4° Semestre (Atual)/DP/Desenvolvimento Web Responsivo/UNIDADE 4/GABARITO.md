## Gabarito Detalhado

### Exercicio 1
**Pergunta:** O que e um framework?

- **A) CORRETA — Estrutura de padroes e componentes reutilizaveis.**
- B) Sistema operacional.
- C) Banco de dados.
- D) Tema visual.
- E) Editor de codigo.

> **Resposta: A** — Um framework e uma estrutura que fornece padroes, componentes e ferramentas reutilizaveis para agilizar o desenvolvimento de software.

---

### Exercicio 2
**Pergunta:** Qual e a vantagem dos frameworks?

- A) Tornam o site mais pesado.
- B) Eliminam a necessidade de HTML.
- **C) CORRETA — Padronizam o layout.**
- D) Removem responsividade.
- E) Substituem JavaScript.

> **Resposta: C** — Frameworks CSS como Bootstrap e Materialize padronizam o layout, acelerando o desenvolvimento com componentes prontos e consistentes.

---

### Exercicio 3
**Pergunta:** Para que serve um Grid System?

- A) Gerar calculos.
- B) Criar paginas backend.
- C) Excluir CSS.
- D) Criar APIs.
- **E) CORRETA — Organizar colunas e layouts responsivos.**

> **Resposta: E** — Um Grid System (como o do Bootstrap) organiza o conteudo em colunas e linhas, facilitando a criacao de layouts responsivos e alinhados.

---

### Exercicio 4
**Pergunta:** Qual tecnologia torna paginas interativas?

- A) HTML
- **B) CORRETA — JavaScript**
- C) CSS
- D) JSON
- E) SQL

> **Resposta: B** — O JavaScript e a linguagem de programacao responsavel por adicionar interatividade e dinamismo as paginas web no lado do cliente.

---

### Exercicio 5
**Pergunta:** O DOM permite o que?

- A) Criar bancos de dados.
- B) Controlar servidores.
- C) Gerar logs.
- **D) CORRETA — Manipular elementos da pagina.**
- E) Converter arquivos.

> **Resposta: D** — O DOM (Document Object Model) e uma representacao em arvore da pagina HTML que permite ao JavaScript acessar, modificar e manipular elementos dinamicamente.

---

### Exercicio 6
**Pergunta:** Qual pratica contribui para acessibilidade?

- **A) CORRETA — Navegacao por teclado.**
- B) Contraste baixo.
- C) Textos minusculos.
- D) Animacoes excessivas.
- E) Layout fixo.

> **Resposta: A** — A navegacao por teclado e uma pratica essencial de acessibilidade, permitindo que pessoas com deficiencias motoras utilizem o site sem mouse.

---

### Exercicio 7
**Pergunta:** Qual boa pratica com JavaScript?

- A) Misturar JS dentro do HTML.
- B) Criar muitos scripts grandes.
- C) Evitar arquivos externos.
- **D) CORRETA — Manter codigo limpo e organizado.**
- E) Colocar todos os scripts no topo da pagina.

> **Resposta: D** — Manter o codigo limpo e organizado (separado do HTML, modularizado e bem comentado) e uma das principais boas praticas no desenvolvimento com JavaScript.

---

### Exercicio 8
**Pergunta:** Materialize CSS e baseado em qual sistema visual?

- A) Flat Design.
- **B) CORRETA — Material Design.**
- C) Skeumorfismo.
- D) Neon UI.
- E) Bootstrap UI.

> **Resposta: B** — O Materialize CSS e um framework baseado no Material Design, sistema de design criado pelo Google com principios de movimento, profundidade e componentes visuais consistentes.

---

### Exercicio 9
**Pergunta:** O que acessibilidade melhora alem da inclusao?

- A) Custo.
- **B) CORRETA — SEO e experiencia do usuario.**
- C) Seguranca.
- D) Tamanho do arquivo.
- E) Versao mobile.

> **Resposta: B** — Alem da inclusao, a acessibilidade melhora o SEO (mecanismos de busca valorizam sites acessiveis) e a experiencia geral de todos os usuarios.

---

### Exercicio 10
**Pergunta:** Qual tendencia caracteriza o desenvolvimento moderno?

- A) Paginas estaticas.
- B) Sites sem JavaScript.
- **C) CORRETA — Interfaces dinamicas, acessiveis e centradas no usuario.**
- D) Layouts fixos.
- E) Design sem responsividade.

> **Resposta: C** — O desenvolvimento web moderno e caracterizado pela criacao de interfaces dinamicas, responsivas, acessiveis e centradas na experiencia do usuario.
