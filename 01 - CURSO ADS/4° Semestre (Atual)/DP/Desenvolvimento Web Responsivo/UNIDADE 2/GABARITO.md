## Gabarito Detalhado

### Exercicio 1
**Pergunta:** O que significa HTML?

- A) Hyperlinks and Text Markup Language.
- B) High Technology Modern Language.
- **C) CORRETA — Hyper Text Markup Language.**
- D) Home Tool Markup Language.
- E) Hyper Transfer Machine Language.

> **Resposta: C** — HTML significa Hyper Text Markup Language, a linguagem de marcacao padrao para criacao de paginas web.

---

### Exercicio 2
**Pergunta:** O que significa CSS?

- A) Computer Style System.
- B) Creative Style Sheets.
- **C) CORRETA — Cascading Style Sheets.**
- D) Colorful Style System.
- E) Central Styling Software.

> **Resposta: C** — CSS significa Cascading Style Sheets, a linguagem usada para descrever a apresentacao e estilo visual de documentos HTML.

---

### Exercicio 3
**Pergunta:** Qual propriedade CSS altera a cor do texto?

- A) margin
- B) font-size
- C) background-color
- **D) CORRETA — color**
- E) border

> **Resposta: D** — A propriedade `color` define a cor do texto em CSS.

---

### Exercicio 4
**Pergunta:** O HTML define "o que e", e o CSS define:

- A) A logica da pagina.
- **B) CORRETA — A aparencia e o estilo.**
- C) O banco de dados.
- D) A consulta SQL.
- E) A estrutura do servidor.

> **Resposta: B** — Enquanto o HTML estrutura o conteudo, o CSS cuida da aparencia visual: cores, fontes, espacamentos e layout.

---

### Exercicio 5
**Pergunta:** Como aplicar CSS externo?

- A) Dentro de <p>
- B) Dentro de <script>
- C) Com <style> interno
- **D) CORRETA — Com <link rel="stylesheet">**
- E) Apenas inline

> **Resposta: D** — O CSS externo e vinculado ao HTML pela tag <link rel="stylesheet" href="arquivo.css"> no <head>.

---

### Exercicio 6
**Pergunta:** Qual propriedade controla espacamento interno?

- A) border
- **B) CORRETA — padding**
- C) margin
- D) align-content
- E) gap

> **Resposta: B** — `padding` e o espacamento interno entre o conteudo e a borda do elemento.

---

### Exercicio 7
**Pergunta:** Para que serve margin?

- A) Cores.
- B) Altura do texto.
- C) Tamanho da fonte.
- D) Bordas internas.
- **E) CORRETA — Espacamento externo.**

> **Resposta: E** — `margin` controla o espacamento externo ao redor do elemento, separando-o dos elementos vizinhos.

---

### Exercicio 8
**Pergunta:** O que acontece se nao usar CSS?

- A) A pagina nao abre.
- B) O navegador quebra.
- **C) CORRETA — A pagina fica sem estilo.**
- D) JavaScript nao funciona.
- E) Perde acessibilidade.

> **Resposta: C** — Sem CSS, a pagina e exibida com a estilizacao padrao do navegador, sem cores, fontes ou layouts personalizados.

---

### Exercicio 9
**Pergunta:** Qual vantagem do CSS3?

- **A) CORRETA — Permite layouts responsivos.**
- B) Processa banco de dados.
- C) Substitui HTML.
- D) Substitui JavaScript.
- E) Desativa imagens.

> **Resposta: A** — O CSS3 introduziu media queries, flexbox e grid, tornando possivel criar layouts responsivos que se adaptam a diferentes tamanhos de tela.

---

### Exercicio 10
**Pergunta:** Funcao do HTML + CSS juntos formam o que?

- A) Cria sistemas completos.
- B) Executa codigo no servidor.
- **C) CORRETA — Estrutura + aparencia.**
- D) Gerencia roteamento.
- E) Valida formularios.

> **Resposta: C** — HTML fornece a estrutura e o conteudo, enquanto o CSS fornece a aparencia e o estilo visual da pagina.
