## Gabarito Detalhado

### Exercicio 1
**Pergunta:** O que e Front-End?

- A) Parte que gerencia dados no servidor.
- **B) CORRETA — Parte visual e interativa do site.**
- C) Banco de dados da aplicacao.
- D) Linguagem utilizada para APIs.
- E) Parte logica e funcional da aplicacao.

> **Resposta: B** — O Front-End e a parte da aplicacao que o usuario ve e interage diretamente no navegador, composta por HTML (estrutura), CSS (estilo) e JavaScript (interatividade).

---

### Exercicio 2
**Pergunta:** Qual linguagem define a estrutura de uma pagina web?

- A) JavaScript
- B) Python
- **C) CORRETA — HTML**
- D) PHP
- E) Java

> **Resposta: C** — O HTML (HyperText Markup Language) e a linguagem de marcacao responsavel por definir a estrutura e o conteudo de paginas web.

---

### Exercicio 3
**Pergunta:** A tag <header> e um exemplo de:

- **A) CORRETA — Elemento semantico.**
- B) Script funcional.
- C) Elemento grafico.
- D) Estrutura condicional.
- E) Fonte externa.

> **Resposta: A** — A tag <header> e um elemento semantico introduzido no HTML5. Elementos semanticos descrevem seu proprio significado para o navegador e para ferramentas de acessibilidade e SEO.

### Exercicio 4
**Pergunta:** Qual editor e mais recomendado para iniciar no desenvolvimento web?

- A) NetBeans
- **B) CORRETA — VS Code**
- C) Word
- D) CorelDRAW
- E) AutoCAD

> **Resposta: B** — O Visual Studio Code (VS Code) e o editor mais recomendado para iniciantes no desenvolvimento web por ser gratuito, leve, altamente extensivel e com grande suporte da comunidade.

### Exercicio 5
**Pergunta:** Qual funcao o Back-End NAO realiza?

- A) Acesso ao banco de dados.
- B) Validacao de rotas.
- C) Processamento de regras de negocio.
- **D) CORRETA — Criacao de layout visual.**
- E) Controle de sessoes.

> **Resposta: D** — O Back-End nao cria layouts visuais. Essa e responsabilidade do Front-End (HTML/CSS). O Back-End processa logica de negocio, acessa bancos de dados, gerencia rotas e sessoes no servidor.

### Exercicio 6
**Pergunta:** Qual tag representa um paragrafo?

- **A) CORRETA — <p>**
- B) <section>
- C) <label>
- D) <title>
- E) <main>

> **Resposta: A** — A tag <p> (paragraph) e usada para definir paragrafos de texto em HTML. E um elemento de bloco que adiciona espaco acima e abaixo automaticamente.

---

### Exercicio 7
**Pergunta:** Para que serve o atributo lang="pt-br" no HTML?

- A) Aumentar o tamanho da fonte.
- **B) CORRETA — Definir a linguagem da pagina.**
- C) Criar efeitos visuais.
- D) Ativar JavaScript.
- E) Alterar cores.

> **Resposta: B** — O atributo lang na tag <html> define o idioma principal do documento. Auxilia leitores de tela, ferramentas de traducao e mecanismos de busca a interpretar o conteudo corretamente.

---

### Exercicio 8
**Pergunta:** O HTML5 trouxe como evolucao principal:

- A) Animacoes nativas.
- B) Nova sintaxe para JavaScript.
- **C) CORRETA — Tags semanticas.**
- D) Novo banco de dados.
- E) Ferramentas de compilacao.

> **Resposta: C** — A principal evolucao do HTML5 foi a introducao de tags semanticas como <header>, <footer>, <nav>, <article>, <section> e <aside>, que dao significado estrutural ao conteudo da pagina.

---

### Exercicio 9
**Pergunta:** O que significa SEO?

- **A) CORRETA — Search Engine Optimization.**
- B) System Enhanced Output.
- C) Semantic Engine Operation.
- D) Security Enhanced Organization.
- E) Simple Engine Optimization.

> **Resposta: A** — SEO (Search Engine Optimization) e o conjunto de tecnicas para otimizar paginas web e melhorar seu posicionamento nos resultados dos mecanismos de busca como o Google.

---

### Exercicio 10
**Pergunta:** Qual camada reune visual + interacao?

- A) Back-End.
- B) API.
- **C) CORRETA — Front-End.**
- D) Banco de Dados.
- E) Servidor.

> **Resposta: C** — O Front-End e a camada responsavel por reunir o aspecto visual (HTML/CSS) e a interatividade (JavaScript), sendo tudo aquilo que o usuario ve e manipula diretamente no navegador.
